# Team rules

Rules from the owner for everyone working on Trout Trot, including Claude sessions.

1. **Local commits are allowed to save work. Nobody pushes to GitHub.** That includes every Claude session. The owner pushes himself, occasionally.
2. **The director runs every plan by the owner before any task is executed.**
3. **Never go beyond 90% of plan usage**, on either the 5-hour or the weekly limit.
4. **The "Trout Trot DEV" session is the team's developer.**
5. **The "Code Review" session does code review.**

Project conventions (layout, commands, testing, game rules) are in `CLAUDE.md`.
