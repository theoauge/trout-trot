# Trout Trot

A rainbow trout stranded on a bank of the Upper Iowa River near Decorah has to flop back into the water before it dries out. The game is wrapped as an iPhone and Android app with [Capacitor](https://capacitorjs.com).

- App ID: `com.thomas.trouttrot`. It can't be changed after the app is published, so keep it the same for every release.
- Version: 1.1.005 (build 5).

## Layout

| Path | What it is |
|---|---|
| `../flop-home.html` | **The game's source.** The web version, and what the app is built from |
| `www/index.html` | The app's copy of the game. Generated by `npm run build`, so don't edit it by hand |
| `www/fonts/` | Bundled Fredoka and Nunito fonts (SIL Open Font License), so the app works offline |
| `assets/` | Master icon (`icon-1024.png`), Play Store icon (`play-store-icon-512.png`) and splash (`splash-2732.png`) |
| `scripts/` | The build, icon, font and version scripts below |
| `capacitor.config.json` | App name, app ID, splash screen and status bar settings |
| `android/` | Android Studio project (portrait only) |
| `ios/` | Xcode project (portrait only) |
| `../privacy-policy.html` | The privacy policy page the stores ask for |

## Commands

| Command | What it does |
|---|---|
| `npm run build` | Rebuilds `www/index.html` from `../flop-home.html` with local fonts, then copies it into both native projects |
| `npm run icons` | Redraws the icon and splash screen from `scripts/make-icons.mjs` and exports every Android and iOS size |
| `npm run fonts` | Downloads the fonts again into `www/fonts/` (only needed if the game's fonts change) |
| `npm run version:set -- 1.1 2` | Sets the version players see (1.1) and the build number (2) on both platforms |
| `npm run android` / `npm run ios` | Opens the project in Android Studio / Xcode |

After changing the game, always run `npm run build`.

## Releasing an update

1. `npm run version:set -- <version> <build>`. The **build number must go up by at least 1 for every upload** to either store, even when re-uploading the same version. The version (1.0, 1.1, 2.0) is what players see.
2. `npm run build`
3. Build a signed release in Android Studio or Xcode (below) with the same signing key as before.

## Android

**Test on your phone (Windows works):**

1. Install [Android Studio](https://developer.android.com/studio). It includes Java and the Android SDK.
2. `npm run android`, or use **File → Open** on the `android` folder. Wait for Gradle to finish syncing (several minutes the first time).
3. Turn on **Developer options → USB debugging** on your phone, plug it in, pick it in the device menu, and press **Run**.

**Release for Google Play:**

1. **Build → Generate Signed App Bundle or APK → Android App Bundle**, and create a new key the first time.
2. **Back up the key file (`.jks`) and its passwords outside this PC.** Every update must be signed with the same key. Never commit it to Git.
3. Upload the resulting `app-release.aab` in Google Play Console. Start with Internal testing.

## iPhone: needs a Mac

Xcode only runs on macOS. Either:

- **Use a Mac:** install Xcode, run `npm run ios`, choose your Apple ID under **Signing & Capabilities**, plug in your iPhone and press **Run**.
- **Use a cloud build service** such as Codemagic or Ionic Appflow, which build iOS apps on their Macs from a Git repository.

## Store listings

- **Accounts:** Google Play Console (one-time $25) and Apple Developer Program ($99/year).
- **Icon:** `assets/play-store-icon-512.png` for Google Play. Apple uses the icon built into the app.
- **Privacy policy:** `../privacy-policy.html`. Fill in a contact email, then host it at a public web address.
- **Privacy answers:** Google Play data safety is "No data collected, no data shared". Apple's App Privacy label is "Data Not Collected".
- **Also needed:** screenshots, a short and full description, and a content rating questionnaire.
